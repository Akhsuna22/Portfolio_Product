# Anushka — Product Manager Portfolio

A single-page, animated portfolio website — built to showcase 2+ years of product management experience in AI-powered SaaS and operations automation.

Live site: https://portfolio-product-sigma.vercel.app/)

## About

This portfolio highlights:
- Product experience across scheduling automation, AI quality-check systems, and workflow tooling
- Case studies with real impact metrics (manual effort reduced, turnaround time improved)
- A "How I Work" section outlining a Discover → Define → Build → Measure approach
- Skills, education, and ways to get in touch

## Tech

Built as a single self-contained `index.html` file — no build step, no dependencies to install.

- HTML, CSS, vanilla JavaScript
- Scroll-based reveal animations and an interactive, filterable project section
- Layered parallax background for visual depth

## Running locally

Just open `index.html` in any browser — no server or build process required.

## Deployment

This project auto-deploys via [Vercel](https://vercel.com) whenever changes are pushed to the `main` branch.

To make changes:
```bash
git add .
git commit -m "your update message"
git push
```

Vercel will automatically pick up the push and redeploy.
